# Бесплатный direct-режим NewsLight Studio

Цель: новость → готовый вертикальный ролик → личный предпросмотр в Telegram → одно нажатие **✅ Одобрить** → публикация в подключённые соцсети.

По умолчанию `STUDIO_PUBLISHER=review`, поэтому никакая новая соцсеть не получает видео, пока владелец не выполнит однократную авторизацию и не включит direct-режим.

## Поддерживаемые площадки

- YouTube Shorts — официальный YouTube Data API.
- TikTok — официальный Content Posting API / Direct Post.
- Instagram Reels — официальный Instagram API / Content Publishing.
- Facebook Reels — официальный Facebook Page Reels API.
- Telegram — существующий @PurpleHelperBot и @newsLightGG.

Ayrshare оставлен только как необязательный платный запасной вариант. Для direct-режима он не нужен.

## Что делает владелец один раз

Нельзя подключить чужие соцсети одним GitHub-коммитом: каждая площадка требует, чтобы владелец сам вошёл в аккаунт и выдал приложению разрешение. Пароли и токены нельзя отправлять в Telegram-канал, README или чат.

После авторизации значения кладутся только в GitHub **Settings → Secrets and variables → Actions**.

### YouTube

Secret:

- `YOUTUBE_TOKEN_JSON`

В репозитории уже есть `scripts/youtube_auth.py`. OAuth JSON должен содержать refresh token, чтобы Google-клиент мог обновлять короткоживущий access token.

### TikTok

Secrets:

- `TIKTOK_ACCESS_TOKEN`
- `TIKTOK_REFRESH_TOKEN`
- `TIKTOK_CLIENT_KEY`
- `TIKTOK_CLIENT_SECRET`

Нужно TikTok Developer App с Content Posting API и разрешением `video.publish`. При первом direct-запуске студия обновляет токен и дальше хранит вращающиеся access/refresh tokens внутри **зашифрованного** `data/studio-state.enc`. В код и логи они не пишутся.

Перед каждым предпросмотром студия получает Creator Info: конкретный TikTok-аккаунт, доступные уровни приватности и разрешённые настройки комментариев/duet/stitch. Эти значения входят в одобряемую версию. Если аккаунт или допустимые настройки изменились, публикация блокируется до нового предпросмотра.

Variable:

- `STUDIO_TIKTOK_PRIVACY=PUBLIC_TO_EVERYONE`

Если TikTok не предлагает этот уровень приватности (например, из-за статуса приложения/аккаунта), студия не подменяет его другим молча, а останавливает подготовку.

### Instagram Reels

Нужен поддерживаемый Instagram professional account и разрешение на Content Publishing в Meta App.

Secrets:

- `INSTAGRAM_ACCESS_TOKEN`
- `INSTAGRAM_USER_ID`

Видео загружается локально через resumable upload; после обработки контейнера выполняется `media_publish`. Между этими стадиями сохраняется checkpoint, чтобы падение GitHub Actions не создавало дубликаты.

### Facebook Reels

Нужна Facebook Page и Page access token с разрешениями публикации.

Secret:

- `FACEBOOK_PAGE_ACCESS_TOKEN`

Студия стартует Reel upload, загружает MP4, завершает публикацию и затем проверяет статус обработки.

## Включить публикацию после подключения

GitHub → Settings → Secrets and variables → Actions → **Variables**:

- `STUDIO_PUBLISHER=direct`
- `STUDIO_TARGETS=youtube,instagram,tiktok,facebook`
- `STUDIO_ACCOUNT_LABEL=названия твоих аккаунтов`
- `STUDIO_VISIBILITY=public`

Можно оставить только нужные площадки, например:

`STUDIO_TARGETS=youtube,tiktok,instagram`

## Как это работает каждый день

1. Новостной автопилот публикует свежую новость в @newsLightGG и передаёт факты в видеостудию.
2. Студия выбирает лучшие истории в дневной лимит.
3. Делает 1080×1920 MP4, русский voice-over, крупные субтитры и тематический видеоряд.
4. Присылает владельцу **конкретный MP4 + подпись + список аккаунтов/площадок + настройки**.
5. Владелец нажимает **✅ Одобрить**, **🔄 Переделать** или **❌ Отклонить**.
6. Только после ✅ одобренные байты MP4 отправляются в выбранные соцсети.
7. Бот присылает отдельный результат по каждой площадке.

## Защита от неприятных сюрпризов

- Без одобрения публикации нет.
- Одобрение привязано к SHA-256 конкретного MP4, подписи, площадкам, видимости и подключению аккаунта.
- Старые кнопки одобрения не работают после переделки.
- Новость старше 24 часов не публикуется из старого одобрения.
- Перед каждой внешней записью сохраняется encrypted checkpoint.
- Если API оборвался в момент, когда публикация **могла** пройти, статус становится `unknown`; система не делает слепой повтор и не создаёт возможный дубль.
- Успех одной площадки не заставляет повторно отправлять её при ошибке другой.
- TikTok access/refresh token rotation хранится только в encrypted state.

## Футажи

Secret `PEXELS_API_KEY` — необязательный бесплатный ключ Pexels API. С ним ролики используют тематические stock-фрагменты. Без него остаётся собственная motion-графика. Stock используется как иллюстрация темы и не выдаётся за реальную видеозапись конкретного события.

## Стоимость

Сам рендер, Telegram approval, GitHub Actions в текущей публичной конфигурации и direct API-адаптеры не требуют Ayrshare. Сторонние платформы могут менять свои бесплатные квоты, требования к App Review и доступность API. Платная генерация сцен (Kling/Runway и т.п.) не является обязательной частью системы.
