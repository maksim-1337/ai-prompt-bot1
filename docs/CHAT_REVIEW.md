# Разбор переданного чата

Источник: https://chatgpt.com/share/6aa3d1f2-da70-83eb-ac9c-584b813a94a4

Прочитана доступная текстовая переписка. Часть служебных выводов инструментов в опубликованной копии скрыта;
их выполнение проверялось по фактическим файлам GitHub, а не по обещаниям ассистента.

## Установлено

- GitHub: maksim-1337. Пользователь ранее разрешил использовать ai-prompt-bot1.
- Канал переименован с @historyXYT в @newsLightGG. Бот — @PurpleHelperBot.
- Нужна по возможности бесплатная автоматизация, управление с телефона.
- Референс: @yep_news, короткая понятная новость, без внешних ссылок.
- Telegram: жирный заголовок → «Что известно» → blockquote → короткая реакция.
- Предыдущее видео пользователю не понравилось. Нужен выразительный тематический видеоряд.
- В чате описаны тестовые посты; последний — про складной iPhone. Старые тесты не переиздаются.

## До изменений

- Google News RSS, ранжирование, data/seen.json, часовой GitHub Actions.
- main.py и styled_publish.py: карточки с zoom, edge-tts, FFmpeg, sendVideo.
- MoneyPrinterTurbo обсуждался, но в обнаруженном репозитории не был встроен.
- Не было личного одобрения, адаптеров соцсетей и статуса по каждой площадке.
- Совпадение заголовков называлось подтверждением; оно не заменяет фактчекинг.

## Добавлено

- Передача опубликованного Telegram-поста в новую видеостудию, до двух роликов в день.
- Проверка свежести и отказ при недостатке исходного текста.
- Тематические иллюстративные футажи либо оригинальная графика, русский голос и субтитры.
- Одобрение конкретного MP4, подписи и настроек отправки.
- YouTube напрямую либо три сети через отдельно подключаемый Ayrshare.
- Зашифрованная очередь, защита от повторов, отслеживание результата, тесты и инструкция.

## Требуется владельцу

Один раз открыть Telegram-бота и авторизовать свои соцсети. Подключения аккаунтов и разрешения не возникают
из одного коммита. До настройки действует предпросмотр. После настройки обычное действие — одобрение;
истёкший токен, отказ площадки или неизвестный результат отправки иногда требуют вмешательства.
