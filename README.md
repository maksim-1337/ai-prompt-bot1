# HistoryXYT News Autopilot

Бесплатный автопилот для Telegram-канала @historyXYT: собирает свежие новости, отбирает самые интересные, формирует пост и вертикальное видео 9:16, затем публикует в Telegram.

Базовая версия работает без платных AI API. Для улучшения текста можно позже добавить бесплатный Gemini API key.
