# NewsLightGG Autopilot

Бесплатный автопилот для Telegram-канала **@newsLightGG**.

Что делает автоматически:

- собирает свежие новости через Google News RSS;
- отбирает вирусные и обсуждаемые темы: технологии, ИИ, интернет, игры, компании, соцсети, наука, культура и необычные истории;
- учитывает свежесть, ключевые слова и наличие похожей новости у нескольких источников;
- не публикует одну и ту же новость повторно;
- пишет короткий пост в формате: факт → 1–2 предложения деталей → короткая эмоциональная/ироничная концовка;
- **не выводит внешние ссылки и блоки «Источник» в Telegram-посте**;
- делает оригинальное вертикальное видео 1080x1920 с крупной типографикой и лёгкой анимацией;
- сначала пробует бесплатную русскую neural-озвучку через `edge-tts`, а при недоступности переключается на локальный `espeak-ng`;
- собирает MP4 через FFmpeg;
- отправляет видео и короткую подпись прямо в Telegram;
- запускается через GitHub Actions каждый час.

## Telegram

Канал: `@newsLightGG`

Бот получает токен только из GitHub Actions Secret `TELEGRAM_BOT_TOKEN`.

## Ручной запуск

`Actions → NewsLightGG Autopilot → Run workflow`

## Стоимость

Базовая конфигурация не использует платные AI API и не требует отдельного VPS. Внешние бесплатные условия сервисов могут меняться, поэтому проект сделан так, чтобы платные AI-сервисы не были обязательными.
