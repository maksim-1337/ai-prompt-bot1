# NewsLight — автоматические посты с фотографиями

**Активный режим Telegram с 12 сентября 2026: одна проверенная новость примерно раз в 3 часа → подходящая фотография + текст → @newsLightGG. Без одобрения владельцем и без видео в канале.**

Редактор ChatGPT проверяет свежие источники и фотографию, затем передаёт материал в `data/editorial-queue/`. `NewsLightGG Photo Autopilot` публикует через существующего @PurpleHelperBot. При отсутствии подходящей новости или фотографии выпуск пропускается. Между отправками — минимум 3 часа, даже после перезапуска. Ссылки и проверка хранятся в журнале; в публичной подписи ссылок нет.

[Контракт очереди и работа редактора](docs/PHOTO_EDITOR.md). Подтверждения отправки: `data/photo-publications.json`. Первая проверка нового режима проверяет подключение без повторной отправки Roblox.

Ниже сохранена документация отдельной Video Studio для ранее настроенного проекта роликов в соцсети. Она не определяет формат новых Telegram-постов и не получает новые задания от фотоавтопостера.

# NewsLight Studio

**@newsLightGG → вертикальное видео → одобрение в @PurpleHelperBot → подключённые соцсети.**

Студия добавлена в существующий новостной репозиторий. Telegram продолжает получать посты с жирным
заголовком, блоком «Что известно» и цитатой. Студия выбирает до двух опубликованных историй в сутки,
делает отдельные ролики и присылает владельцу на проверку.

**Начальный режим — предпросмотр. Аккаунты TikTok, Instagram и YouTube ещё не подключены.**
Код содержит реальные адаптеры публикации; их нужно включить после однократной авторизации аккаунтов.
Отсутствие ключей не выдаётся за успешную отправку.

## Возможности

- Передача фактов из опубликованной новости в очередь видео.
- Сценарий из текста новости без выдуманных подробностей; публичная подпись без внешних ссылок.
- MP4 1080×1920, 30 fps, H.264/AAC, обычно 15–40 секунд.
- Русский neural-голос Dmitry, синхронные субтитры по 5 слов, смена сцен.
- Тематические иллюстративные футажи Pexels при наличии бесплатного ключа; иначе собственная анимированная графика.
- Личный Telegram: **одобрить / переделать / отклонить**, изменение подписи, пауза.
- Одобрять может только владелец канала (роль creator, проверенная через Telegram).
- Одобрение конкретной версии MP4, подписи, площадок, подключения и видимости.
- Отдельный статус площадок. `pending` не считается публикацией.
- Зашифрованная очередь, контроль повторов и перезапусков. Секреты не записываются в код.
- Работа через GitHub Actions, без постоянно включённого компьютера.

Это автоматический монтаж из фактов, озвучки, футажей и графики. Платная генерация видеосцен через
Runway/Kling не входит в базовую версию. MoneyPrinterTurbo обсуждался в исходном чате, но фактический
автопостер использовал свой Python/FFmpeg-код; студия продолжает эту архитектуру.
[Разбор исходного чата](docs/CHAT_REVIEW.md).

## Первый шаг с телефона

1. Открой [@PurpleHelperBot](https://t.me/PurpleHelperBot?start=studio), нажми **Start / Запустить**.
   Это должен сделать владелец @newsLightGG. Бот должен оставаться администратором канала.
2. Дождись запуска **NewsLight Video Studio**, расписание — каждые 15 минут.
   При необходимости: [Actions](https://github.com/maksim-1337/ai-prompt-bot1/actions) →
   **NewsLight Video Studio → Run workflow**.
3. Бот подтвердит подключение владельца и после новой подходящей новости пришлёт MP4.
   Новости из одного заголовка без фактов пропускаются. До подключения публикации ролик можно сохранить.

Существующий `TELEGRAM_BOT_TOKEN` используется повторно. **Токены в чат и в файлы кода не отправляй.**

## Подключить соцсети

GitHub: **Settings → Secrets and variables → Actions**. Secrets — ключи, Variables — настройки.

| Режим | Подключение | Результат |
|---|---|---|
| `review`, по умолчанию | Существующий Telegram-бот | Готовые ролики лично владельцу |
| `youtube` | OAuth своего YouTube-канала | Загрузка Shorts после одобрения без сервиса кросспостинга |
| `ayrshare` | Свои аккаунты и API-ключ Ayrshare | TikTok, Instagram Reels, YouTube Shorts после одобрения |

### Три сети через один сервис

1. В [Ayrshare](https://www.ayrshare.com/) подключи **свои** TikTok, Instagram и YouTube.
   Это внешний сервис со своим тарифом. Подписка и платежи в этом проекте не оформлялись.
2. Создай Secret `AYRSHARE_API_KEY`.
3. Создай Variables:
   - `STUDIO_PUBLISHER` = `ayrshare`
   - `STUDIO_TARGETS` = `youtube,instagram,tiktok` (оставь только подключённые сети)
   - `STUDIO_ACCOUNT_LABEL` = имена подключённых аккаунтов, понятные тебе в карточке одобрения
4. Студия пришлёт новый предпросмотр. Проверь аккаунты в панели Ayrshare и нажми **Одобрить публикацию**.

Публикация идёт в аккаунты подключённого профиля Ayrshare. Публичная видимость выбрана по умолчанию и
показана в карточке. У TikTok выключены комментарии, дуэты и stitch, включена маркировка AI-контента.
Музыка и рекламные интеграции не добавляются. Перед одобрением показана Music Usage Confirmation.
Код не обходит требования, аудит или региональные ограничения площадок.

### YouTube напрямую

1. В своём Google Cloud включи YouTube Data API v3, настрой OAuth consent screen.
2. Создай OAuth client типа **Desktop app**, скачай его JSON.
3. На компьютере один раз выполни:

```bash
python -m pip install -r requirements-studio.txt
python scripts/youtube_auth.py client_secret.json
```

4. В открывшемся Google выбери канал и разреши загрузку видео.
5. Содержимое `youtube-token.json` добавь в GitHub Secret `YOUTUBE_TOKEN_JSON`.
6. Variables: `STUDIO_PUBLISHER=youtube`, `STUDIO_ACCOUNT_LABEL=имя твоего канала`.

Загрузки из непроверенных API-проектов Google могут быть ограничены приватным режимом.
OAuth в статусе Testing может требовать повторного подключения. Проверяй видимость в YouTube Studio:
загрузка не всегда означает публичную публикацию. Для настройки целиком с телефона проще внешний сервис.

## Футажи и стоимость

Добавь Secret `PEXELS_API_KEY` из [Pexels API](https://www.pexels.com/api/).
Без ключа используется собственная графика. Футажи иллюстрируют тему и не выдаются за кадры конкретного события.
Подбор по ключевым словам требует твоей визуальной проверки. Автор, адрес и лицензия записываются в manifest;
публичные подписи остаются без ссылок.

Монтаж и графика локальные, обязательного платного AI API нет. `edge-tts` использует внешний бесплатный
сервис без гарантии доступности: его сбой останавливает подготовку, а не создаёт немой рабочий ролик.
Стандартные GitHub Actions runner в публичных репозиториях по текущим условиям бесплатны; задания могут
задерживаться или пропускаться. Это не гарантия сервера 24/7. Полностью бесплатная стабильная публикация
сразу во все сети не обещается. Тариф Ayrshare оплачивается отдельно только если владелец его выберет.

## Управление

| Команда / кнопка | Действие |
|---|---|
| `/status` | Очередь и режим |
| `/pause` | Пауза новых публикаций и подготовки; уже переданное площадке не отменяется |
| `/resume` | Продолжить |
| Одобрить | Отправить показанную версию в показанные аккаунты |
| Переделать | Пересобрать и запросить новое одобрение |
| Отклонить | Закрыть ролик |
| `/caption ID текст` | Изменить подпись; требуется новый предпросмотр |
| `/retry ID` | Повторить неудавшуюся подготовку, без автоодобрения |

Кнопки обрабатываются при следующем запуске, обычно с задержкой 15–30 минут, иногда больше.
Новости старше 24 часов не публикуются. Неопределённый результат отправки требует проверки кабинета площадки,
а не автоматического повтора. В таком случае потребуется вмешательство.

Variables: `STUDIO_DAILY_LIMIT` (по умолчанию 2, максимум 4), `STUDIO_ENABLED=false` (отключить студию),
`STUDIO_VOICE`, `STUDIO_VISIBILITY` (`public` или `private`; Instagram требует `public`).
Не запускай второй getUpdates или webhook на том же боте.

## Надёжность и данные

Перед публикацией сохраняется зашифрованное намерение, после ответа — tracking ID и результат.
Отправка на уже обработанную площадку не повторяется при сбое другой. Таймаут требует проверки, а не слепого
повтора. Абсолютное exactly-once для внешних API не обещается. Исходный MP4 хранится в Telegram как документ
и перед отправкой проверяется по SHA-256. Лимит 19 MB позволяет повторно скачать файл через Bot API.

**Не удаляй `data/studio-state.enc`: там одобрения и защита от дублей.**
Ключ выводится из токена Telegram. Перед ротацией токена установи Secret `STUDIO_STATE_KEY` равным
**старому токену**, затем меняй `TELEGRAM_BOT_TOKEN`: алгоритм вывода ключа одинаков.
Не меняй STUDIO_STATE_KEY без миграции очереди. Повреждённая очередь/неверный ключ останавливают работу.
Завершённые задания удаляются из активной очереди через 7 дней; неизвестные результаты сохраняются.

Система проверяет структуру и свежесть, но **не выполняет полноценный фактчекинг**. Похожие заголовки
в исходном автопостере не доказывают независимое подтверждение. Источник и замечания показаны владельцу
в личном предпросмотре. Подробности из одного заголовка не выдумываются.

## Разработка

```bash
python -m pip install -r requirements-studio.txt
python -m unittest discover -s tests -v
python -m studio demo             # офлайн-макет; звук может отсутствовать
python -m studio demo --voice     # настоящая neural-озвучка, нужен интернет
python -m studio run              # рабочий цикл с переменными окружения
```

`.env.example` — образец; `.env` автоматически не загружается. Локально экспортируй переменные в оболочке.
GitHub передаёт их через workflow. Video Studio Checks запускает тесты и собирает демо без секретов
и публикаций; MP4 доступен в артефактах workflow.

Локально прошли 18 тестов, включая чужое одобрение, старые кнопки, смену подписи/назначения,
повреждение очереди, истёкшую новость, частичный сбой, таймаут, перезапуск и отказ записи состояния.
Собран и проверен реальный MP4 1080×1920. Живая отправка в соцсети и neural-озвучка не проверялись
без подключений аккаунтов и доступа к соответствующим внешним сервисам.
