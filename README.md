# HistoryXYT News Autopilot

Бесплатный автопилот для Telegram-канала **@historyXYT**.

Что делает автоматически:

- собирает свежие новости через Google News RSS;
- отбирает темы про технологии, ИИ, интернет, игры, крупные компании, соцсети, науку и громкие события;
- учитывает свежесть, ключевые слова и наличие похожей новости у нескольких источников;
- не публикует одну и ту же новость повторно;
- делает оригинальный вертикальный визуал 1080x1920 без копирования чужих фотографий;
- создаёт русскую озвучку локально через `espeak-ng`;
- собирает MP4 через FFmpeg;
- публикует видео и подпись со ссылкой на источник в Telegram;
- запускается бесплатно через GitHub Actions каждые 2 часа.

## Что нужно один раз настроить

В GitHub открой:

`Settings → Secrets and variables → Actions → New repository secret`

Создай секрет:

- Name: `TELEGRAM_BOT_TOKEN`
- Secret: токен бота @PurpleHelperBot, полученный у @BotFather

Токен нельзя добавлять в код, README, Issues или отправлять публично.

После добавления секрета можно открыть:

`Actions → HistoryXYT News Autopilot → Run workflow`

Это запустит первый тест вручную. После этого расписание продолжит работу автоматически.

## Стоимость

Базовая конфигурация не использует платные AI API и не требует VPS. Для публичного репозитория стандартные GitHub-hosted runners можно использовать без оплаты согласно правилам GitHub Actions. Внешние сервисы могут менять свои бесплатные условия, поэтому проект сделан так, чтобы платные AI-сервисы не были обязательными.

## Качество текста

Без AI ключа бот использует заголовок, доступное описание RSS и шаблон. Позже можно опционально подключить бесплатный tier Gemini для более естественных формулировок. Если бесплатная квота Gemini закончится или ключ отсутствует, базовый режим продолжит работать.
